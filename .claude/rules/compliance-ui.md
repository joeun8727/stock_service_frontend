# 14 — 컴플라이언스 UI (필수 준수)

> ⚠️ 백엔드의 `08-compliance.md`와 짝을 이루는 화면 규칙입니다. 모든 데이터 화면에 적용됩니다.

## 1. 면책 문구 노출 (필수)

- **전역 푸터**에 면책 문구 상시 노출 (`components/common/Disclaimer`):
  > "본 정보는 투자 추천이나 자문이 아니며, 정보 제공만을 목적으로 합니다. 투자 결정과 책임은 이용자 본인에게 있습니다."
- API 응답의 `disclaimer` 필드를 받아 데이터 화면(섹터/종목/뉴스) 하단에도 표시.
- 면책 문구를 시각적으로 숨기거나(0px, display:none) 사용자가 못 보게 처리 금지.

## 2. 뉴스 표시 규칙

- 뉴스는 **헤드라인 + 자체 LLM 요약 + 출처명 + 원문 링크**만 표시.
- **원문 본문 전체를 화면에 렌더링 금지** (백엔드가 저장하지도 않음).
- 각 뉴스 항목에 **출처 링크(외부)** 를 명확히 노출하고, "원문 보기"로 출처 사이트 이동.
- 외부 링크는 `target="_blank"` + `rel="noopener noreferrer"`.

## 3. 표현 가이드 (유사투자자문업 회피)

화면 문구에서 매수/매도 권유로 해석될 표현 금지:

| 금지 | 대체 |
|------|------|
| "추천 종목", "지금 매수" | "시가총액 상위 종목", "성장 지표 상위 종목" |
| "유망주 BEST" | "섹터 내 지표 순위" |
| "오를 종목", "목표가" | (제공 안 함) — 지표/사실만 표시 |

- 랭킹/Top20은 **"객관적 지표 기반 정렬"** 임을 화면에 명시 (예: "시가총액 순", "성장 점수 순").
- 섹터 "유망도"는 **"지표 기반 점수"** 라는 설명 툴팁/캡션을 동반.

## 4. 데이터 신선도 표시

- 랭킹/지표/뉴스에 **기준 시각**(예: "2026-05-29 06:00 기준") 표시. 사용자가 데이터 시점을 알 수 있게.

## 체크리스트 (새 화면 추가 시)

- [ ] 투자 권유성 표현이 없는가?
